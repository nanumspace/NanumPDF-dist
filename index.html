x64와 ARM64, 어떤 파일을 받아야 하나요?

설정 → 시스템 → 정보 → 시스템 종류를 확인하세요. “x64 기반 프로세서”는 x64, “ARM 기반 프로세서”는 ARM64를 선택합니다. 이 페이지는 PC 종류를 자동으로 판단하지 않습니다.

NanumPDF는 무료로 사용할 수 있는 비공개 소스 소프트웨어입니다. 설치 전에 전체 이용 조건을 확인하고, 동의하는 경우에만 설치·사용해 주세요.

GET STARTED

확인하고, 설치하고, 열어보세요.

현재 사용자 계정에 설치되며, 다른 사용자 계정에는 설치되지 않습니다.

  1. 파일 받기와 확인

    PC 종류에 맞는 MSI와 해당 SHA-256 파일을 받으세요. 아래 안내에 따라 체크섬과 디지털 서명을 모두 확인합니다.

  2. 설치 옵션 선택

    MSI를 더블 클릭하고 설치 마법사를 진행합니다. 기본 경로는 %LocalAppData%\Programs\NanumPDF입니다.

    바탕화면 바로가기와 PDF 연결 프로그램 등록은 기본으로 선택되어 있습니다. 원하지 않으면 설치 화면에서 해제하세요.

  3. NanumPDF 실행

    시작 메뉴에서 NanumPDF를 실행하고 PDF를 열어보세요. 설치만으로 PDF 기본 앱이 바뀌지는 않습니다.

    기본 앱으로 쓰려면 설정 → 앱 → 기본 앱에서 .pdf를 NanumPDF로 지정하세요.

설치 전 확인

파일의 출처와 무결성을 확인하세요.

1. SHA-256 체크섬 비교

받은 .sha256 파일을 메모장으로 열고 해시 값을 확인합니다. 다운로드 폴더에서 PowerShell을 열어 아래 명령의 Hash 값과 비교하세요. 대소문자를 제외한 모든 문자가 같아야 합니다.

Get-FileHash .\NanumPDF-1.0.0-win-x64.msi -Algorithm SHA256

ARM64 파일은 명령의 파일명을 NanumPDF-1.0.0-win-arm64.msi로 바꿔 실행하세요.

2. 유효한 디지털 서명 확인

MSI를 우클릭해 속성 → 디지털 서명 → 자세히에서 서명이 유효한지 확인하세요. 인증서의 서명자와 발급자는 아래 표기와 일치해야 합니다.

서명자
Nanum Space Co,. Ltd
발급자
GlobalSign GCC R45 EV CodeSigning CA 2020

서명자의 Co,.는 인증서에 등록된 실제 표기입니다.

PowerShell에서도 서명 상태가 Valid인지 확인할 수 있습니다.

(Get-AuthenticodeSignature .\NanumPDF-1.0.0-win-x64.msi).Status

ARM64는 위 안내와 같이 파일명을 바꿔 확인하세요.

Windows SmartScreen 경고가 나타나나요?

새로 배포된 파일은 평판이 충분히 쌓이기 전까지 경고가 표시될 수 있습니다. 경고만으로 안전 여부를 판단하지 마세요. 체크섬 일치, 유효한 서명, 정확한 서명자와 발급자를 모두 확인하기 전에는 실행하지 마세요. 값이 다르거나 서명이 없거나 유효하지 않다면 설치를 중단하고 문의해 주세요. 확인이 어렵다면 경고를 우회하지 마세요.

GOOD TO KNOW

자주 묻는 질문

무료로 사용할 수 있나요? 오픈 소스인가요?

누구나 비용 없이 내려받아 설치하고 사용할 수 있습니다. 다만 소스 코드는 공개하지 않으며, 모든 권리는 Nanum Space Co., Ltd.(나눔스페이스)에 있습니다. 재배포와 수정은 금지되며, 역공학은 법령이 명시적으로 허용하는 범위를 제외하고 금지됩니다. 전체 조건과 제3자 구성 요소에 관한 사항은 LICENSE.txt를 확인하세요.

.NET이나 관리자 권한이 필요한가요?

필요하지 않습니다. 설치 파일에 .NET 런타임이 포함되어 있으며, 현재 사용자 계정에만 설치됩니다. Windows 10 또는 Windows 11의 x64·ARM64 환경을 지원합니다. 32비트 Windows, macOS와 Linux용 설치 파일은 제공하지 않습니다.

업데이트는 어떻게 하나요?

자동 업데이트 기능은 없습니다. 릴리스 페이지에서 새 버전의 설치 파일과 변경 내용을 확인하고, 서명과 체크섬을 확인한 뒤 설치하세요. 이전 설치는 새 설치 파일로 교체됩니다.

PDF 기본 앱으로 설정할 수 있나요?

설치에서 PDF 연결 프로그램 등록을 선택하면 Windows의 앱 목록에 NanumPDF가 표시됩니다. 기본 앱은 자동으로 바뀌지 않습니다. PDF를 우클릭해 연결 프로그램 → 다른 앱 선택에서 NanumPDF를 선택하고 항상을 누르거나, 설정 → 앱 → 기본 앱에서 .pdf의 기본 앱을 변경하세요.

다른 사람에게 설치 파일을 보내도 되나요?

설치 파일과 포함된 파일의 재배포는 허용되지 않습니다. 파일을 복사하거나 다시 게시하는 대신 이 다운로드 페이지의 주소를 알려 주세요.

제거하거나 문제를 문의하려면 어떻게 하나요?

설정 → 앱 → 설치된 앱에서 NanumPDF를 제거할 수 있습니다. Windows 10에서는 앱 및 기능 목록을 사용하세요. 설정과 로그 폴더 %LocalAppData%\NanumPDF는 남을 수 있으며 필요 없다면 직접 삭제할 수 있습니다.

문의와 오류 보고는 support@nanumspace.com으로 보내 주세요. Windows 버전, PC 종류, NanumPDF 버전과 오류 내용을 함께 알려 주시면 도움이 됩니다. 문서에 개인정보가 있다면 보내지 마세요. 공개 배포 저장소에서는 이슈를 받지 않습니다.
